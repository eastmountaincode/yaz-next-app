# Furniture model credits

The furniture models in this directory are optimized website copies of the
original GLB downloads. Both source models are licensed under CC BY 4.0. The
`wooden_table` source included a transparent 68-by-68-unit ground plane; that
export artifact was removed so the environment editor scales the table itself.

- `wooden_table_optimized.glb`: “Wooden table” by
  [Hrisan](https://sketchfab.com/Hrisan), from
  [Sketchfab](https://sketchfab.com/3d-models/wooden-table-7fc479c22ffa4a0eb4000390ce17170e).
- `old_wooden_table_optimized.glb`: “Old Wooden Table” by
  [MaX3Dd](https://sketchfab.com/MaX3Dd), from
  [Sketchfab](https://sketchfab.com/3d-models/old-wooden-table-c4ddf03df3904e6e963d3d20d8df5b48).
